# Real-Time Weather Data Analysis and Forecasting Using Python

## Project Overview
This project retrieves hourly weather forecast data from the Open-Meteo API and analyzes it using Python. An interactive Streamlit dashboard displays weather statistics and visualizations for multiple cities.

## Features
- Fetch hourly weather forecasts using the Open-Meteo API
- Analyze temperature, humidity, rainfall and wind speed
- Calculate statistical summaries using NumPy, Pandas and SciPy
- Visualize trends and distributions using Matplotlib and Seaborn
- Select from six Indian cities
- Refresh weather data on demand
- Download weather data as a CSV file

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- SciPy
- Requests
- Streamlit
- Open-Meteo API

## Installation
1. Install Python.
2. Download or clone this repository.
3. Install dependencies:

   `python -m pip install -r requirements.txt`

4. Run the data analysis script:

   `python main.py`

5. Launch the dashboard:

   `python -m streamlit run dashboard.py`

## Data Source
Weather forecasts are retrieved from the [Open-Meteo API](https://open-meteo.com/).

## Limitations
The project displays forecast data, not guaranteed observations of actual weather. Data refresh requires an internet connection.
